# RefFind — Strategic Referral Outreach

> Stop sending cold referral requests to random employees. Find the people who are actually close to the role.

RefFind parses a job description and returns a tiered list of contacts at the company — ranked by how strategically valuable their referral would be. Same team beats same company, every time.

---

## The Problem

Random referrals (e.g. someone you know who works at the company but in a completely different function) carry very little weight with hiring managers. A referral from someone on the same team — or even the same desk — is an entirely different signal.

RefFind solves this by identifying:

| Tier | Who | Why it matters |
|------|-----|----------------|
| **Tier 1** | Same role, same team | They know the hiring manager personally and can speak directly to day-to-day responsibilities |
| **Tier 2** | Different role, same team | Works on the same desk — can vouch for team fit and potentially make a warm intro |
| **Tier 3** | Adjacent team or peer firm | Related function or same role at a competitor — softer but still a warm connection |

---

## Features

- **JD parsing** — Paste any job description; AI extracts company, team, department, seniority, and key skills
- **Tiered contact discovery** — 9 contacts per search, 3 per tier, ranked by referral value
- **Personalised outreach drafts** — Copy-ready messages tailored to each contact's role and your background
- **Tier filtering** — Focus on Tier 1 contacts first, expand outward as needed
- **Search history** — All past JD searches saved locally with SQLite
- **Multi-source support** — LinkedIn (browser), Apollo.io (API), RocketReach (API)

## Getting Started

### Prerequisites

- Node.js 18+
- An [Anthropic API key](https://console.anthropic.com/)

### Installation

```bash
git clone https://github.com/praneethk002/Refind.git
cd Refind
npm install
```

### Environment

Create a `.env` file in the project root:

```env
ANTHROPIC_API_KEY=sk-ant-...
```

### Run (development)

```bash
npm run dev
```

The app runs on [http://localhost:5000](http://localhost:5000). Express serves the backend on the same port via Vite middleware.

### Build (production)

```bash
npm run build
NODE_ENV=production node dist/index.cjs
```

## How It Works

```
Paste JD
   │
   ▼
Claude parses JD
→ extracts: company, team, department, seniority, skills, search queries
   │
   ▼
Contact generation
→ queries LinkedIn / Apollo / RocketReach with team-specific search phrases
→ each contact scored and tiered by proximity to the role
   │
   ▼
Results page
→ contacts grouped by tier, each with tier reason + personalised outreach draft
→ filter by tier, copy message, open LinkedIn profile
```

---

## Data Source: Apify LinkedIn Search

Real contacts come from the [`aeonkosmos/linkedin-employee-search`](https://apify.com/aeonkosmos/linkedin-employee-search) Apify actor.

- Uses Google X-ray search — no LinkedIn login, no cookies, no ban risk
- Filters by company name + job title keyword
- Returns: name, headline, LinkedIn profile URL
- Costs ~$0.002 per result

### How the 3 searches map to tiers

```
Tier 1 search: company="Goldman Sachs" title="Credit Risk Analyst"
Tier 2 search: company="Goldman Sachs" title="Structured Finance Associate"
Tier 3 search: company="Goldman Sachs" title="Leveraged Finance"
```

Title filters are generated by Claude Haiku based on the JD — not hardcoded.

### Cost per search

| Stage | Service | Est. cost |
|-------|---------|----------|
| Regex extraction | None | $0 |
| Team + tier query generation | Claude Haiku | ~$0.0005 |
| LinkedIn search (~11 results) | Apify | ~$0.022 |
| Outreach drafts | Claude Haiku | ~$0.001 |
| **Total** | | **~$0.024/search** |
